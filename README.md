++ DailyBoard 

++ Fitur Utama

- Manajemen Tugas (To-Do List): Tambah, edit, hapus, dan tandai status penyelesaian tugas.
- Catatan Harian: Simpan ide atau catatan penting dengan penanggalan otomatis.
- Widget Cuaca Real-time.
- Kutipan Motivasi Harian.
- Mode Gelap / Terang: Beralih tema tampilan sesuai kenyamanan mata pengguna.
- Penyimpanan Lokal (LocalStorage).

++ Teknologi yang Digunakan

- HTML5
- CSS
- JavaScript 
- API 

 ++ Cara Penggunaan Aplikasi

1. Mengelola Tugas (To-Do List)
- Menambah Tugas
- Menandai Selesai 
- Mengedit Tugas
- Menghapus Tugas

2. Mengelola Catatan
- Menambah Catatan
- Menghapus Catatan

3. Mengubah Tema Tampilan
 - Klik tombol **Mode Gelap / Mode Terang
